The Water Quality Index is a Brown-style Weighted Arithmetic WQI (weighted mean of per-parameter sub-indices). A lower value indicates better quality: 0-25 Excellent, 25-50 Good, 50-75 Poor, 75-100 Very Poor. Each sub-index is 0 at the ideal value and 100 at the permissible limit. It is a screening indicator of overall quality, not a per-parameter regulatory verdict and not a potability certification.

Parameter standard check (permissible values used by the WQI)

Each parameter below is checked against the same permissible value the WQI sub-index uses. Dissolved oxygen, BOD and total coliform use official CPCB Class A limits; conductivity and fecal coliform are adopted project thresholds (CPCB Class A specifies no value for them); nitrate uses a WHO drinking-water guideline converted to the as-N basis. The sub-index q shows how far the value sits between the ideal (q=0) and the permissible limit (q=100). "Within/Outside" refers only to these project-selected thresholds - it is not regulatory compliance, not a potability verdict, and does not certify the water is safe to drink.
